# 🎵 工作流步骤列表优化

## 📊 优化概述

### 问题
之前所有项目类型都使用相同的步骤列表（180天音乐计划的步骤），不适合其他类型的项目。

### 解决方案
为每个项目类型创建专门的默认步骤列表，同时保留用户自定义步骤的能力。

## 🎯 新增的工作流模板

### 1. 180天音乐计划专用 (`beginner-180-workflow`)
**适用项目**: 新手音乐人计划

**步骤列表** (10步，共40小时):
1. 新曲风前期准备（7小时）- 听10张专辑，研究曲风
2. 确定子曲风和参考歌（2小时）
3. 制作Demo（8小时）
4. Demo审核（1小时）
5. 完成编曲（12小时）
6. 编曲审核（1小时）
7. 混音母带（6小时）
8. 混音审核（1小时）
9. 队长审核（1小时）
10. 校长审核（1小时）

**特点**: 包含完整的学习和审核流程，适合新手

---

### 2. 专业音乐人流程 (`professional-workflow`)
**适用项目**: 专业音乐人

**步骤列表** (7步，共26小时):
1. 确定创作方向和参考（1.5小时）

3. Demo自审与调整（1小时）

**特点**: 跳过前期研究，更高效，适合有经验的音乐人

5. 详细编曲制作（15小时）
6. 编曲细节打磨（5小时）

8. 混音细节处理（4小时）
9. 母带处理（2小时）
10. 多设备试听和调整（2小时）

## 🔧 技术实现

### 1. 工作流模板结构

```javascript
{
  id: 'workflow-id',
  name: '工作流名称',
  description: '描述',
  isDefault: true,
  isCustom: false,
  applicableTypes: ['song', 'track'],
  projectTypes: ['beginner-180'],  // 新增：关联的项目类型
  steps: [
    {
      name: '步骤名称',
      estimatedHours: 2,
      description: '步骤描述'
    }
  ]
}
```

### 2. 项目模板关联

每个项目模板现在指定其默认工作流：

```javascript
{
  id: 'beginner-180',
  name: '新手音乐人计划',
  defaultWorkflowId: 'beginner-180-workflow',  // 关联专用工作流
  ...
}
```

### 3. 自动选择工作流

新增 Store 方法：

```javascript
// 根据项目类型获取推荐的工作流
getWorkflowsForProjectType(projectType)

// 根据项目类型获取默认工作流
getDefaultWorkflowForProjectType(projectType)
```

### 迁移策略
```javascript
// 创建新作品时
if (project.templateId) {
  // 使用项目模板的默认工作流
  const template = getTemplateById(project.templateId)
  const workflow = getWorkflowById(template.defaultWorkflowId)
  track.customSteps = workflow.steps

  // 使用通用工作流
```
